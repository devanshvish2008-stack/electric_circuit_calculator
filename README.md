# Electric Circuit Calculator

## 1. Project Overview

The Electric Circuit Calculator is a beginner-friendly Python project designed to perform common electrical calculations quickly and easily.

The project uses basic electrical formulas to calculate voltage, current, resistance, power, series resistance, and parallel resistance.

The calculator provides a simple menu-driven interface where users can select the required calculation, enter the necessary values, and receive the result.

---

## 2. Features

The Electric Circuit Calculator includes the following features:

- Calculate Voltage using Ohm's Law
- Calculate Current using Ohm's Law
- Calculate Resistance using Ohm's Law
- Calculate Electrical Power
- Calculate total resistance of resistors connected in series
- Calculate total resistance of resistors connected in parallel
- Menu-driven interface
- User-friendly input and output
- Error handling for invalid values
- Option to perform multiple calculations
- Exit option to close the program

### Formulas Used

**Voltage:**

V = I × R

**Current:**

I = V / R

**Resistance:**

R = V / I

**Power:**

P = V × I

**Series Resistance:**

Rtotal = R1 + R2 + R3 + ...

**Parallel Resistance:**

1/Rtotal = 1/R1 + 1/R2 + 1/R3 + ...
