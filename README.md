# Electric Circuit Calculator

#  1. Project Overview

The Electric Circuit Calculator is a  Python project designed to perform common electrical calculations quickly and easily.

The project uses basic electrical formulas to calculate voltage, current, resistance, power, series resistance, and parallel resistance.

## 2.     Features
The Electric Circuit Calculator includes the following features:

- calculate term  using Ohm`s Law: 
voltage
current
resistance
electrical Power
total resistance of resistors connected in series
total resistance of resistors connected in parallel
- User-friendly input and output
- Error handling for invalid values
- Option to perform multiple calculations
- Exit option to close the program

# Formula Used

Voltage: V = I × R

Current: I = V / R

Resistance: R = V / I

Power: P = V × I

Series Resistance:

Rtotal = R1 + R2 + R3 + ...

Parallel Resistance:

1/Rtotal = 1/R1 + 1/R2 + 1/R3 + ...
